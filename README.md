# Flux

Flux es una aplicación web desarrollada para la gestión integral de compras, ventas y control de stock de un negocio multipropósito.

El sistema permite administrar clientes, proveedores, productos, marcas y categorías, centralizando toda la información necesaria para la operación comercial. Además, brinda herramientas para el control de inventario, el registro de movimientos de stock y la generación de ventas con facturación.

## Funcionalidades principales

* Gestión de clientes y proveedores.
* Administración de productos, marcas y categorías.
* Asociación de productos con uno o más proveedores.
* Control de stock actual y stock mínimo.
* Registro de compras con actualización automática de inventario.
* Registro de ventas con validación de stock disponible.
* Generación automática de facturas con numeración única.
* Cálculo dinámico de precios de venta a partir del último precio de compra y el porcentaje de ganancia configurado para cada producto.
* Gestión de usuarios y seguridad mediante autenticación.
* Perfiles de acceso diferenciados:

  * **Administrador:** acceso completo al sistema.
  * **Vendedor:** acceso limitado al registro y gestión de ventas.

## Objetivo

Flux busca optimizar la administración de negocios mediante la automatización de procesos de compra, venta y control de inventario, proporcionando información actualizada y reduciendo errores operativos.
